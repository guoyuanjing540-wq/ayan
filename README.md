# 阿衍

一个人用的聊天网页 App，接智谱 GLM（open.bigmodel.cn）。单文件，没有后端。

- 打开网址 → 左上角 → 设置：填智谱 API Key，导入人格包（.md，第一部分是人设、第二部分是记忆卡）。
- Key、人设、记忆、对话都只存在自己设备的浏览器里，这个仓库里没有任何个人信息。
- iPhone：Safari 打开 → 分享 → 添加到主屏幕，就跟 App 一样用。
- 外观：白色 / 深夜 / 跟着手机。
- 跟 GPT 一样：顶上点名字换模型；右上角虚线圈是临时对话（不进列表、不用也不改记忆）；对话列表「⋯」能置顶、改名、分享、复制全文、下载；设置里有自定义指令、记忆开关。
- 改了页面记得把 `sw.js` 里的 `CACHE` 版本号加 1，手机上才会换新的。
